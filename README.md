# Clothing Payment Service

Handles payment initiation and status tracking for the clothing platform.

## Responsibilities
- Initiate payments
- Track payment status
- Integrate with external payment gateways (future)

## Tech Stack
- Python (FastAPI)
- Docker
- AWS (ECR, EKS)
- Helm

- 

## API Endpoints
- POST /payments/initiate
- GET /payments/{payment_id}
- GET /health
